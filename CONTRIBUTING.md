# Contributing

Thanks for your interest in Kestro UI.

Kestro UI is designed, built and maintained by a single author so that the components keep one consistent design and API. Because of that:

- **Pull requests are not accepted.** The repository only allows collaborators to open pull requests.
- **Issues are welcome.** If something is broken, confusing or missing, please [open an issue](https://github.com/HimasRafeek/kestro-ui/issues/new/choose) with a minimal reproduction or a clear description of the use case.
- **Forks are welcome.** The code is MIT licensed, so you can fork it and adapt it for your own projects.

## Writing a good bug report

1. The `kestro-ui`, React and Tailwind CSS versions you use.
2. What you expected to happen, and what happened instead.
3. A minimal code sample, or a link to a CodeSandbox or StackBlitz.
4. Browser and operating system, if the problem is visual.

## Security issues

Please don't open public issues for vulnerabilities. See [SECURITY.md](./SECURITY.md).
